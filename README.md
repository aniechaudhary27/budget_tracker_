# Personal Budget Tracker Using Python

## 1. Project Documentation
This project is a Personal Budget Tracker developed using Python in Google Colab. It helps analyze financial transactions and manage income, expenses and savings.

## 2. Project Overview
The Personal Budget Tracker analyzes financial transaction data using Python. It calculates total income, expenses, savings and monthly budget status. It also provides category-wise expense analysis and identifies the highest expense.

## 3. Objectives
- To calculate total income and expenses.
- To calculate total savings.
- To analyze category-wise expenses.
- To generate monthly financial reports.
- To identify the highest expense.
- To monitor monthly budget limits.

## 4. Technologies Used
- Python
- Google Colab
- Pandas
- NumPy

## 5. Dataset
- **Source:** Kaggle
- **Format:** CSV (downloaded in ZIP format)
- **Total Records:** 277
- **Total Columns:** 11 (before data cleaning)
- **Currency:** INR

The dataset contains Date, Account, Category, Note, INR, Income/Expense, Amount and Currency.

## 6. How to Run
1. Download the project notebook from GitHub.
2. Open Google Colab.
3. Upload the `.ipynb` file.
4. Download the dataset ZIP file from Kaggle.
5. Run the notebook.
6. Upload the dataset when prompted.
7. Execute all cells one by one to view the results.
